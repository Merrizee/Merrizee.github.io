# MCP、插件与MCP Apps

这三个名词分别描述通信标准、能力打包和聊天内交互界面，理解它们需要分层看待。

## 1. MCP、插件、MCP Apps 的区别

- **MCP** 是通信协议。
- **插件**是功能的打包和安装方式，可以包含 MCP 配置、技能说明、脚本等；具体内容由插件决定。
- **MCP Apps** 是界面扩展，让服务提供的交互式 HTML 界面显示在支持它的 AI 宿主中。

普通工具可以返回文字、数据、链接；MCP Apps 还能关联 UI 资源，让用户在聊天里操作查看器、表单等界面。详见 [MCP Apps 官方说明](https://modelcontextprotocol.io/extensions/apps/overview)。

官方 draw.io 分别提供 Tool Server 和 App Server。本文安装的 npm 包属于 Tool Server；App Server 支持聊天内嵌图形。安装一个 MCP 不代表自动获得两种实现，是否内嵌还取决于宿主支持情况。
