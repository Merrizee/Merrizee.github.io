# 奥格登基础英语 850 词（Ogden's Basic English）

> Charles Kay Ogden 于 1930 年提出 Basic English：使用 850 个基础词及配套语法，通过组合和释义表达更多概念。它是一套简化英语体系，不代表背完词表就能理解 90% 的日常英语。
> 结构：100 操作词 + 600 事物词 + 150 性质词 = 850 词

---

## 一、OPERATIONS 操作词（100 词）

### 18 个核心动词（Operators）
> Basic English 的核心操作词，包括动词及 may、will 等助动词；练习用这些词与名词、介词组合表达动作。

| | | | | | |
|---|---|---|---|---|---|
| be | come | do | get | give | go |
| have | keep | let | make | may | put |
| say | see | seem | send | take | will |

### 介词 / 方向词（Prepositions & Direction）

| | | | | |
|---|---|---|---|---|
| about | across | after | against | among |
| at | before | between | by | down |
| from | in | into | near | of |
| off | on | out | over | through |
| till | to | under | up | with |
| within | without | | | |

### 连词（Conjunctions）

and, because, but, for, if, or, so, than, that, though, when, while

### 其他操作词

a, the, all, almost, as, back, certain, clearly, completely, different, early, enough, equally, ever, every, far, first, forward, generally, here, how, last, late, little, long, more, most, much, necessary, no, not, now, one, only, opposite, other, perhaps, quite, right, same, second, self, short, still, such, then, there, very, well, what, where, who, why, yes, yet

## 五、学习建议

| 阶段 | 建议 |
|---|---|
| **第一步** | 先记住 18 个核心动词，掌握它们的基本用法 |
| **第二步** | 学习 100 个操作词（介词、连词等），这些是句子骨架 |
| **第三步** | 按场景分批记忆图形事物词（200词），结合图片记忆效率最高 |
| **第四步** | 补充综合事物词和性质词，完成 850 词体系 |
| **核心思想** | 用这 850 词替换生僻词，锻炼用简单词表达复杂意思的能力 |
